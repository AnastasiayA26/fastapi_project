- **CRUD-эндпоинты с жёсткой валидацией**  
  Все входящие и исходящие данные описаны в Pydantic-схемах (`src/schemas.py`), а роутеры в папке `src/routers/` автоматически проверяют типы, обязательность полей и допустимые значения.  

- **JWT-аутентификация и управление правами**  
  Пользователь регистрируется и логинится через специальные эндпоинты, при этом при каждом запросе защищённых маршрутов проверяется действительность JWT-токена и права доступа. Логика  реализована в `src/main.py` и вспомогательных модулях.  

- **Взаимодействие с базой данных**  
  Подключение к PostgreSQL настраивается в `src/database.py` (SQLAlchemy + asyncpg). Все CRUD-операции инкапсулированы в `src/crud.py`, что обеспечивает единообразную работу с сессиями, транзакциями и моделями (`src/models.py`).  

- **Контейнеризация и локальный запуск**  
  `docker-compose.yml` поднимает сервис API вместе с базой в контейнерах. Папка `docker/postgres/` содержит Dockerfile и скрипты инициализации схемы и тестовых данных.  

- **Набор unit-тестов**  
  Покрытие ключевой логики реализовано через pytest/unittest.
  Тесты проверяют:  
    - корректность CRUD-операций  
    - обработку невалидных запросов 
    - работу JWT-механизма (генерация, истечение срока, отказ в доступе)
